# Real Estate Agency Landing Page — Prestige Realty

> **Issue:** [#21816](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/21816)

## Overview

A complete copy-paste ready full-page real estate agency landing page built using EaseMotion CSS classes. Features a professional, trustworthy aesthetic with gold accent colours on a dark background. All 8 required sections are implemented.

## EaseMotion CSS Classes Showcased

| Class | Applied To |
|---|---|
| `ease-fade-in-down` | Sticky navbar, hero badge |
| `ease-fade-in-left` | Hero headline, sub-copy |
| `ease-fade-in-up` | Hero CTAs, hero stats, property cards, feature cards, testimonials, CTA section |
| `ease-zoom-in` | Property search bar, agent profile cards |
| `ease-fade-in` | Neighborhood cards |

## Sections Implemented

- **Hero** with property search bar (type, location, price range filters) and stats (clients, sales, satisfaction)
- **Featured Listings Grid** with 6 hover cards (tag badges: New, Featured, Sold), bed/bath/sqft specs
- **Agent Profiles** — 4 agent cards with avatar, name, title, and deal count
- **Why Choose Us** — 3 feature cards (ratings, verification, price guarantee)
- **Neighborhood Showcase** — 4 neighborhood cards with listing count
- **Testimonials** — 3 client stories from buyers and sellers
- **Contact CTA** banner with consultation and browse actions
- **Footer** with 4-column links (Properties, Company, Support)

## How to Test

1. Open `demo.html` directly in a browser (no build step required).
2. Verify the sticky navbar with blur backdrop renders correctly.
3. Scroll through all 8 sections and observe entrance animations.
4. Hover over property listing cards — verify the lift and shadow effect.
5. Check responsive layout at ≤ 768px and ≤ 1024px viewport widths.
6. Verify the property search bar form elements are styled and interactive.
